Three original reference packets exposed two defects. Calendar grounding omitted actual changed event readbacks, rejecting a correct answer about the new current event. Drive reconstructs the observed chain from its saved initial checkpoint, retains raw observations and validates the actual incomplete frontier/provider refusal; a partial outcome must keep the saved checkpoint. No-read guesses, invented records/cursors, claimed completeness and wrong deltas remain invalid.

The shared page-chain implementation also prevents rereading an earlier page from erasing an issued terminal checkpoint or overriding a later file disposition.
